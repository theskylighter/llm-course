# Sample Study Site

Welcome! This is the **home page** (`content/lessons/index.md`). Replace this text with a short introduction: who the course is for, how each lesson is laid out, and how to use the practice sets.

Every lesson follows the same rhythm:

1. **The problem**: what goes wrong without this idea.
2. **The idea in plain words**, then a **real-world analogy**.
3. **How it works**, step by step, with code or a diagram.
4. **Key takeaways**, **common mistakes** and **how it's asked in exams**.
5. **Quick check** questions with hidden answers.
